# Adobe Becker Style Studio + Viktim

Кроссплатформенное (Win/Linux/macOS/Android/iOS) приложение на **Kivy** —
рабочая область в духе Adobe Animate, в которой живёт стикмен **Viktim**
(в стиле Alan Becker: Animator vs. Animation).

## Запуск (Windows / Linux / macOS)
```
pip install -r requirements.txt
python main.py
```

## Android
```
pip install buildozer
buildozer -v android debug
```
(`buildozer.spec` уже приложен, требования = python3,kivy,numpy)

## iOS
```
pip install kivy-ios
toolchain build python3 kivy
toolchain create AdobeBeckerApp .
# открыть сгенерированный .xcodeproj в Xcode и собрать
```

## Файлы
- `main.py` — Kivy-приложение, тулбар, HUD, игровой цикл (30 fps).
- `workspace.py` — холст рисования (кисть/награда/угроза), объекты сцены.
- `viktim.py` — тело/скелет Viktim, восприятие сцены, декодирование мозга в движение.
- `brain.py` — мозг: 150 AdEx-нейронов, 2 полушария по 75, ~15000 синапсов
  (внутриполушарные + межполушарные "мозолистое тело"), оси дофамин/серотонин/
  норадреналин/кортизол (HPA).
- `neuron.py` — векторизованная AdEx-модель нейрона и разреженная матрица синапсов
  (экспоненциальные токи + лёгкий STDP).

## Важное честное пояснение
Это не имитация в смысле "заранее записанная анимация" — поведение Viktim
(идти/бежать/подходить/бездействовать, углы суставов, скорость) на 100%
определяется выходом спайковой сети и гормональных осей, реагирующих на то,
что происходит на холсте (нарисованные объекты помечены как "угроза" или
"награда"). Это функциональная, качественно правдоподобная модель базовых
нейро-эндокринных контуров (детекция угрозы/миндалина, вознаграждение/дофамин,
ось стресса HPA/кортизол, серотонин как модулятор импульсивности) — но
150 нейронов не создают сознание или субъективный опыт; это симуляция
поведенческих механизмов, а не искусственное сознание.
